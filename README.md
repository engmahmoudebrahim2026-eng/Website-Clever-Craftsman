# 📌 About The Project

**Clever Craftsman** is a modern Front-End website designed to present
craftsmanship, services and creative solutions through an attractive
and easy-to-navigate interface.

The project focuses on combining **modern UI/UX design, responsive layouts
and interactive elements** to create a professional web experience.

It was developed as part of my journey in **Front-End Web Development**
and as a practical project to improve my web development skills.
